## ⚙️ Run Locally

To run this portfolio on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/divyankakri7-oss/divyanka-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd divyanka-portfolio
   ```

3. Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.
